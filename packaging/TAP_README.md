# BardiaN/homebrew-tap

Homebrew formulae for my open-source tools.

```bash
brew tap BardiaN/tap
brew install kronk-cli
```

| Formula | |
|---|---|
| [`kronk-cli`](https://github.com/BardiaN/kronk-cli) | Terminal agent for local models served by [Kronk](https://github.com/ardanlabs/kronk) |

Formulae here are updated automatically by each project's release workflow. Please open issues
against the project repository rather than this one.
